Sourcing and changelog note

All weapon stats come from the fan-maintained wiki wikiwiki.jp/incursionrr, in Japanese. Fields shown as "single-sourced, unconfirmed" have exactly one source: this wiki. No English-language wiki or calculator for this game was found as of 2026-10-27 across repeated searches.

Two weapons' muzzle-velocity figures (AK-74M, Colt M4A1) are shown alongside a real-world reference figure for the actual firearm the in-game weapon is modeled on. That reference describes a different gun's published spec, not this game's tuned number — it is shown for context, not as a second source confirming the in-game value, per this build's data-honesty rule.

The wiki's own category pages cite different in-game version numbers against each other: the DMR page cites version 1.0.14.4, the sniper rifle page cites version 1.1.0.1. This may mean some category pages were last updated on different patches. Stats here are shown as currently published per page, not normalized to one patch version.

Two weapons (FN Five-Seven, FN P90) are listed by the source wiki with 9x19mm ammunition, though both real-world firearms are chambered in 5.7x28mm. Shown as published, not corrected, per this build's rule against silently merging real-world and in-game facts.

One rifle-category table row on the source wiki (7.62x51mm, 700rpm, 300m effective range) links to a page that returns "no such page," so its name cannot be read from the wiki. It is excluded from this tool rather than guessed.

No damage, recoil, or armor-penetration numbers exist anywhere on the source wiki for any weapon, so no "effective DPS" or ranking is computed or shown here.
